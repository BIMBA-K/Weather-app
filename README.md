Weather App 🌤️

A simple weather app that shows the weather of a city.

Features

- Search for a city
- View temperature
- View weather condition
- View humidity
- View wind speed

Technologies

- HTML
- CSS
- JavaScript
- Weather API

How to Run

1. Download or clone the project.
2. Open "index.html".
3. Search for a city.
4. View the weather.
